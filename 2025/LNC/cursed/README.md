## cursed
Author: Kairos  
Challenge prompt: You've been hexed! Can you REVERSE the clues to REVERSE the curse?  
Challenge files are available at https://github.com/Lag-and-Crash/2025-public/tree/main/challenges/forensics  

This is a very easy steganography challenge. I ran  
`  
strings curse.png | grep "LNC"  
`  

which outputted the flag immediately.  
Flag: LNC25{cUr53s_r3v3r53D}
